# Matrizes rastreáveis

- [Requisitos](requisitos.json): 32 requisitos, com gate/fase e condição de aceite.
- [Casos de teste](casos_de_teste.json): 60 casos especificados; todos começam em `NOT_RUN` porque o SaaS não foi testado nesta entrega.

Não são planilhas de resultados nem prova automática de cobertura. O Codex deverá ligar cada caso a uma implementação/teste real, registrar comandos e classificar bloqueios. Manter o snapshot original deste pacote; integrar progresso nos registros existentes, sem editar hashes para fingir identidade com o pacote entregue.

Uma categoria candidata não autoriza mover o item integralmente. `Migrator`, por exemplo, exige decomposição de responsabilidade após inspeção; sua indicação inicial não significa que toda persistência seja legado.
