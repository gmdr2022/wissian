# Relatório de incremento — modelo

**Fatia / marco / branch / commit / data / ambiente:** preencher com estado observado.

- Resultado demonstrável e fluxo atendido:
- Fontes e decisões de absorção, incluindo alternativa rejeitada:
- Arquivos e contratos alterados; trabalho anterior preservado:
- Requisitos atendidos e evidência real (comando, resultado, oráculo, ambiente):
- Testes NOT_RUN/BLOCKED/SKIPPED, motivo e risco:
- Validação de uso/humana/dispositivo e estado do checkpoint:
- Dados, autorização, efeitos externos e rollback:
- Commit/push/publicação: realizado com referência verificável ou não realizado:
- Pendências necessárias, dono e próximo passo:

Não copiar logs com segredos/dados reais nem transcrição de sessão. Durable contracts and sanitized results belong in the existing repository records; do not create a session diary or require a vault update.
